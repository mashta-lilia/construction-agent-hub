# Тема і стилі

## Як перемикається тема

Bootstrap 5.3 керує світлою/темною темою через атрибут `data-bs-theme` на
кореневому елементі. Джерела істини два, і обидва потрібні:

1. Інлайн-скрипт в `index.html` виставляє атрибут **до** завантаження бандла —
   інакше перший кадр блимне світлим фоном.
2. `providers/ThemeProvider.tsx` тримає стан (`light` / `dark` / `system`),
   пише вибір у `localStorage` під ключем `rehub-theme` і слухає системну
   `prefers-color-scheme`.

Компоненти беруть тему через `useTheme()`, а не через локальний `useState`.

## Де живуть стилі

| Що                                                                                         | Де                                                         |
| ------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| Глобальні правила, імпорт Bootstrap, спільні утиліти (`.rehub-numeric`, `.rehub-sortable`) | `src/index.css`                                            |
| Стилі кореневого лейауту                                                                   | `src/App.css`                                              |
| Спільний «дурний» компонент                                                                | `src/components/<Name>/<Name>.css` — по файлу на компонент |
| Все всередині фічі                                                                         | один `src/features/<name>/<name>.css` на всю фічу          |

## Головне правило кольорів

Не хардкодити палітру. Bootstrap 5.3 віддає власні CSS-змінні, які самі
перевертаються разом із `data-bs-theme`:

```css
/* правильно — працює в обох темах без дублювання */
background-color: var(--bs-secondary-bg);
color: var(--bs-secondary-color);
border-color: var(--bs-border-color);

/* неправильно — доведеться писати другий набір правил під темну тему */
background-color: #f8f9fa;
```

Те саме в JSX: `text-body-secondary`, `bg-body-tertiary`, `text-bg-primary`,
`border` — це утиліти, що вже враховують тему. Прототип робив навпаки: фарбував
літералами і перекривав кожен клас у блоці `html.dark`, і саме тому там
накопичилось 80 правил, які треба було тримати синхронними вручну.

## Розмір CSS

Повний `bootstrap.min.css` — близько 230 КБ (31 КБ gzip). Якщо це стане
проблемою, наступний крок — перейти на імпорт Bootstrap через SCSS і підключати
лише потрібні частини (`scss/_grid.scss`, `_buttons.scss` тощо) замість
готового бандла. Робити це варто після того, як стане видно фактичний набір
використаних компонентів, а не наперед.
